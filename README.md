# Кинопоиск free

Пользовательский скрипт (Userscript) для Tampermonkey, который добавляет кнопку бесплатного просмотра фильмов и сериалов на страницах Кинопоиска.

## Установка

### GreasyFork

1. Установите менеджер пользовательских скриптов, например [Tampermonkey](https://www.tampermonkey.net/), в ваш браузер.
2. Перейдите на страницу скрипта на [GreasyFork](https://greasyfork.org/ru/scripts/580585-кинопоиск-free).
3. Нажмите кнопку **"Установить этот скрипт"**.

### GitHub

1. Установите менеджер пользовательских скриптов, например [Tampermonkey](https://www.tampermonkey.net/), в ваш браузер.
2. Зайти во вкладку Utilities
3. Вставить в поле Import from URL ссылку https://raw.githubusercontent.com/Rnbonnie/kinopoisk-free/refs/heads/master/kp-free.js
4. Нажмите кнопку **"Install"**.

### Вручную

1. Установите менеджер пользовательских скриптов, например [Tampermonkey](https://www.tampermonkey.net/), в ваш браузер.
2. Создайте новый скрипт в панели управления Tampermonkey.
3. Скопируйте содержимое файла `kp-free.js` и вставьте его в редактор.
4. Нажмите **File > Save** (Файл > Сохранить).

## Использование

После установки скрипта на страницах фильмов и сериалов появится зеленая кнопка. Нажмите на неё, чтобы открыть альтернативный плеер в новой вкладке.
