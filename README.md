# Кинопоиск free

Пользовательский скрипт (Userscript) для Tampermonkey, который добавляет кнопку бесплатного просмотра фильмов и сериалов на страницах Кинопоиска.

## Основные возможности

- **Умная кнопка**: Автоматически меняет текст на "Смотреть фильм" или "Смотреть сериал" в зависимости от типа контента.
- **Интеграция с HD**: Работает как на основном сайте `kinopoisk.ru`, так и в онлайн-кинотеатре `hd.kinopoisk.ru`.
- **Нативный дизайн**: Кнопка гармонично вписывается в интерфейс Кинопоиска.
- **Альтернативный плеер**: Перенаправляет на сервис `kinokino.vip` с сохранением ID фильма.

## Установка

1. Установите менеджер пользовательских скриптов, например [Tampermonkey](https://www.tampermonkey.net/), в ваш браузер.
2. Создайте новый скрипт в панели управления Tampermonkey.
3. Скопируйте содержимое файла `kp-free.js` и вставьте его в редактор.
4. Нажмите **File > Save** (Файл > Сохранить).

## Использование

После установки скрипта на страницах фильмов и сериалов появится кнопка с градиентом. Нажмите на неё, чтобы открыть альтернативный плеер в новой вкладке.
